# Built-in ICC profiles

`sRGB-v2-micro.icc` (456 bytes, ICC v2.1, monitor class, RGB) is the compact sRGB profile of
[Compact-ICC-Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles) by Clinton Ingram, released under
CC0 1.0 Universal (public domain dedication): no notice is required. Downloaded on 2026-11-27 from
`profiles/sRGB-v2-micro.icc` of the `master` branch; checked with LittleCMS (Pillow ImageCms) against its built-in
sRGB: the colors of a test set are unchanged.

It is the profile of `HpdfDocument.SRgbProfile` and of the PDF/A output intent.
