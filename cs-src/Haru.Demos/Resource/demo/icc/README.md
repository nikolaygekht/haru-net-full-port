# ICC demo resources

- `ProPhoto-v2-micro.icc` - a wide-gamut RGB profile from
  [Compact-ICC-Profiles](https://github.com/saucecontrol/Compact-ICC-Profiles) by Clinton Ingram (CC0 1.0, public domain)
- `hues-prophoto.jpg` - a hue strip made with Pillow, with that profile embedded (APP2 ICC_PROFILE)
- `hues-plain.jpg` - the same pixels without a profile
